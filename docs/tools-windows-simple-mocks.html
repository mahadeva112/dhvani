Tools — ক্লিক করলেই খোলে, আর প্রতিটা window একই ধাঁচে

১) Tools-এর তালিকায় কোনো নামে ক্লিক করলে সেটার নিজের window সোজা খুলে যায় — মাঝখানের "Now" পাতা আর "Open …" বোতাম আর নেই।
২) নয়টা window-ই এখন একই খোলসে: ছোট রঙিন icon + নাম + এক লাইন + গোল ✕ উপরে, নিচে বাঁয়ে Reset/লেখা আর ডানে Done। সাদা icon tile, পেছনের আলো, আলাদা আলাদা হেডার — সব এক রকম হয়েছে। ভেতরের সেটিং সব আগের মতোই আছে, শুধু সাজানো সহজ। নতুন লেখা মানে যেখানে সাজানোয় বড় বদল।
