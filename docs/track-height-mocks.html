Edit timing — track height

দুটো mock। দুটোতেই track-এর নিচের দাগ মাউসে ধরে উপর-নিচে টানলে সেই track লম্বা বা সরু হয়, waveform-ও সঙ্গে বড়-ছোট হয়। মাউস দাগের উপর নিলে নীল দাগ দেখায়। নিজে টেনে দেখুন।

Mock A — প্রতিটা track আলাদা

শুধু টেনে। প্রতিটা track নিজের মাপ রাখে। দাগে double-click করলে আগের মাপে ফেরে।
  • track-এর নামের ঘর বা lane, দুই জায়গার নিচের দাগ থেকেই টানা যায় (REAPER-এর মতো)।
  • খুব সরু করলে M / S / fader লুকিয়ে শুধু নাম থাকে। লম্বা করলে clip-এর waveform আরও স্পষ্ট হয়।
  • Ruler, Script, Start drift, Whole dub-এর মাপ বদলায় না।
  • মাপ project-এর সঙ্গে রাখা থাকে, আবার খুললে একই থাকে।

Mock B — আলাদা + সব একসঙ্গে

Mock A-র সব কিছু, তার সঙ্গে Shift চেপে টানলে সব track একসঙ্গে, আর উপরে Track height-এর চারটে মাপ।
Track height
Shift + টানা = সব track · double-click = আগের মাপ
  • S / M / L / XL চাপলে সব track একবারে সেই মাপে যায়। তারপর যেকোনো track আলাদা করে টানা যায়।
  • একটা track টেনে বদলালে উপরের বোতামে কোনোটাই বাছা থাকে না (মাপ মিশ্র)।
